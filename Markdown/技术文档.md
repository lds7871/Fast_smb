# SMB快连 技术文档（原 FastSMB）

> .NET MAUI Android SMB 客户端：连接 SMB 服务器 → 浏览共享目录 → 文件预览 / 单个下载 / 批量下载。
> 支持暗色/亮色主题切换、中英文语言切换。
> 本文档面向**用户与 AI**，帮助快速了解文件架构与关键知识点。最后更新：2026-10-03（新增「排序」（§8.2）、「图片预览左右滑动切换」（§8.3）与「浏览位置记忆」（§8.1）；上一发布版 v1.20：删除功能、后台断线自动重连）。

## 3. 页面与导航

- **AppShell**：单 `ShellContent`（ConnectPage）+ `Routing.RegisterRoute("browser", FileBrowserPage)`。
- 连接成功 → `Shell.Current.GoToAsync("browser")` 压栈；浏览器根目录按返回 → 弹回连接页。
- **连接页 OnAppearing 会主动 `SmbSession.Disconnect()`**：退出到主界面即断开（产品约定）。
- 预览页用 `Navigation.PushAsync(new PreviewPage(...))` 直接压栈（不走路由，便于传字节数组）；**图片预览会把同目录图片清单一起传过去**，页内左右滑动切换（见 §8.3）。
- 文件夹层级：`FileBrowserPage` 内部维护 `_pathStack`（返回键优先弹层级，而不是退出页面）。
- **浏览位置记忆**：`FileBrowserPage._scrollMemory`（路径 → 首个可见条目的名称+索引），进入子目录/返回上级/刷新/预览返回后自动回到原位置（详见 §8.1）。

## 4. SMB 核心实现（Services/SmbSession.cs + SmbClients.cs）

### 4.1 连接
1. `Smb2ClientEx.Connect(host, port)`：DNS 解析 → 取 IPv4 → 调 SMBLibrary 的 `protected internal Connect(IPAddress, DirectTCPTransport, port)`。
2. `Login("", user, pass)`（NTLMv2）。
3. SMB2 连接失败 → 回退 `Smb1ClientEx`（SMB1，forceExtendedSecurity=true）。
4. 主机栏支持三种写法：`IP` | `IP:端口` | `IP/共享名` | `IP:端口/共享名`（ConnectPage 解析，端口默认 445）。

### 4.2 共享与目录
- `ListShares()`：经 IPC$ 枚举，**过滤以 `$` 结尾的隐藏共享**（IPC$/ADMIN$ 等）。
- `OpenShare(share)`：`TreeConnect`，句柄存 `_fileStore`（SMB2FileStore 或 SMB1FileStore）。
- `ListDirectory(path)`：
  - **路径规则（重要）**：SMB2 CREATE 的 Name 必须是**相对共享、不带前导反斜杠**；根目录用空串 `""`。真实 Samba 对 `"\\"` 返回 `STATUS_INVALID_PARAMETER`（impacket 测试服务器宽容，掩盖了此问题）。
  - **QueryDirectory 语义（重要）**：返回最后一批条目时同时带 `STATUS_NO_MORE_FILES`——必须**先处理 results 再判断退出**，否则目录永远为空。
  - `FileDirectoryInformation` 的字段是**公共字段**（FileName/EndOfFile/FileAttributes/LastWriteTime），不是属性。

### 4.3 下载
- `DownloadFileAsync(path, Stream output, IProgress<double>, CancellationToken)`：
  CreateFile(GENERIC_READ) → GetFileInformation(FileStandardInformation) 取大小 → 循环 ReadFile（64KB）→ 写入调用方提供的 Stream。
- 落盘由 `DownloadSaver.CreateDownloadStream` 决定：Android 10+ 用 MediaStore（公共下载目录，免权限）；旧版直写公共目录；其他平台写应用数据目录。

### 4.4 删除
- `DeleteEntry(path, isDirectory)`：`CreateFile`（**DELETE 访问权限位 `(AccessMask)0x00010000`** + `CreateOptions.FILE_DELETE_ON_CLOSE`）→ `CloseFile` 触发删除 → **再验证条目是否已消失**（关闭时删除可能被静默忽略，如目录非空/文件被占用）。
- ⚠️ **不能用 `AccessMask.GENERIC_ALL`**：Samba 对 `GENERIC_ALL + FILE_DELETE_ON_CLOSE` 返回 `STATUS_INVALID_PARAMETER`（SMBLibrary 1.5.7.1 无命名 `AccessMask.DELETE`，需直接写权限位）。
- 空目录可删；非空目录删除被服务器静默忽略，由验证步骤返回「目录非空，无法删除」。

## 6. 语言切换（中文/英文）

### 6.1 涉及文件
| 文件 | 作用 |
|---|---|
| `Services/L10n.cs` | **本地化管理器**：`Zh`/`En` 两套 `Dictionary<string,string>`（各 114 个 key，含 SmbSession 错误文案）；`IsEnglish`；`this[key]` 索引器；`SetLanguage(bool)`（触发 INotifyPropertyChanged 全量刷新）；`Load()`（Preferences 恢复） |
| `App.xaml.cs` | 构造函数：`L10n.Instance.Load()` |
| `Pages/ConnectPage.xaml(.cs)` | 语言按钮（右上角「中 / EN」） |
| 所有页面 XAML | 文本绑定：`{Binding [key], Source={x:Static l10n:L10n.Instance}}` |

### 6.2 方法
- **XAML 绑定模式**：`Text="{Binding [notes_title], Source={x:Static l10n:L10n.Instance}}"`。
  `L10n` 用**字符串索引器** + `PropertyChanged(null)`（全属性刷新），切语言时所有此类绑定即时更新。
- **代码取文本**：`L10n.Instance["key"]`（如进度标签 `$"{L10n.Instance["downloading"]} {entry.Name} …"`）。
- **切换**：`L10n.Instance.SetLanguage(!IsEnglish)` → 存 `Preferences("lang")` → 全量刷新。
- **启动恢复**：App 构造函数 `L10n.Instance.Load()`（默认 zh）。
- ⚠️ 数据模板内使用本地化绑定时，**不要写 `x:DataType`**（编译绑定与 `Source={x:Static}` 组合易出错）；FileBrowserPage 的条目模板已移除 x:DataType，退回运行时绑定。

### 6.3 增加新文案的步骤
1. `L10n.cs` 的 `Zh`/`En` 各加一个 key。
2. XAML 里用 `{Binding [key], Source={x:Static l10n:L10n.Instance}}`；代码里 `L10n.Instance["key"]`。

### 8.1 浏览位置记忆（返回上级不回到顶部）

**目标**：在目录里往下翻后进入子文件夹（或预览文件、刷新、上传、删除后重载），返回/回到该目录时仍停在原来的位置。

**做法**（全部在 `Pages/FileBrowserPage.xaml.cs`，页面级内存，不落盘）：

| 成员 | 作用 |
|---|---|
| `_scrollMemory` | `Dictionary<路径, (Name, Index)>`：每个目录上次的首个可见条目 |
| `_scrollCapture` | 最近一次采集到的位置（带 Path，标明属于哪个目录） |
| `OnFileListScrolled` | `CollectionView.Scrolled` → 记 `FirstVisibleItemIndex` 对应条目的**名称+索引** |
| `CommitScrollPosition` | 把采集值按它自己的 Path 存档（换目录、刷新前调用） |
| `PrepareDirectoryChange` | 切换目录前：存档 + 打开 500ms 静默窗 |
| `RestoreScrollPositionAsync` | 载入完成后 `FileList.ScrollTo(条目, ScrollToPosition.Start, animate:false)` |

**要点/坑**：
1. **程序性滚动会污染采集**：`ItemsSource` 被替换（加载目录、清空搜索）时，Android 侧会补发一次 index=0 的 `Scrolled` 事件，若直接连续采集会把上一级的存档覆盖成 0。因此三级过滤：`_loading`（加载中）、`_restoringScroll`（恢复滚动中）、`_scrollSettleUntil`（切换目录 500ms / 载入完成 300ms 静默窗）期间一律不采集。
2. **按名称定位**：存档时同时记名称与索引，恢复时先在当前列表里按名称找（上传/删除导致条目增减、位置偏移也能命中），找不到再退回索引（越界则钳到列表末尾），目标就是第 0 项时不滚动。
3. **恢复要在条目布局完成之后**：`ScrollTo` 紧跟 `ItemsSource` 赋值可能被吞掉 → 先 `Task.Delay(40)` 再滚一次，`Task.Delay(70)` 后补一次兜底；整个恢复过程在 `LoadingPanel` 遮罩之下完成，用户看不到跳动。
4. **范围**：记忆随 `FileBrowserPage` 实例存活，退出到连接页即失效（页面被弹出）。
5. **排查日志**：`adb logcat -s FastSMB:I` 看 `ScrollSave: path=… name=… index=…` 与 `ScrollRestore: path=… target=… index=…`。

### 8.2 排序（日期/名称，四种方式）

**入口**：浏览器顶栏「排序」（在「上级」左边）→ `SortPickerView` 弹窗（遮罩 + 紫边卡片，与共享选择弹窗同款），四个按钮 `日期（新）/ 日期（旧）/ 名称（A）/ 名称（Z）` + 取消；**当前生效的方式用强调色实心按钮高亮**。

| 成员 | 作用 |
|---|---|
| `Services/SortSettings.cs` | `SortMode` 枚举（`DateNew/DateOld/NameAsc/NameDesc`）+ `Current`（Preferences `sort_mode`，默认 `NameAsc`）+ `Apply(list)` + `TextKey(mode)` / `All` |
| `SortPickerView.ShowAsync(current)` | 显示弹窗，返回选中的 `SortMode?`（取消 = null），淡入淡出后自动隐藏 |
| `FileBrowserPage.OnSortClicked` | 选完调 `ApplySortAsync`；`_sortPickerOpen` 期间返回键只关弹窗 |
| `FileBrowserPage.ApplySortAsync` | 存偏好 → 就地重排 `_currentEntries` → 强制重建列表 → 回到顶部 → 横幅提示 |

**要点**：
1. **文件夹始终优先**：`SortSettings.Apply` 先比 `IsDirectory`，同类内部才按所选方式比较（日期用 `LastWriteTime`，名称用 `string.Compare(OrdinalIgnoreCase)`）。
2. **不重新请求服务器**：排序在内存里就地做（`List.Sort`）。但 `ApplySearch` 会把**同一个 List 实例**再赋给 `ItemsSource`，绑定不会触发刷新 → 必须先把 `ItemsSource = null` 再 `ApplySearch()`，列表才会按新顺序重建。
3. **切排序后回到顶部**：顺序变了，旧的首个可见条目不再适用 → 清掉 `_scrollCapture`、开静默窗、`ScrollTo(0)`（与 §8.1 的采集过滤共用一套开关）。之后进入子目录再返回，仍按**名称**恢复到同一批条目位置。
4. **持久化**：`sort_mode` 存 Preferences，重启应用后仍然生效（已在真机验证）。
5. **加载时应用**：`LoadDirectoryAsync` 取回条目后立即 `SortSettings.Apply(_currentEntries)`，所以每个目录都用统一方式排序。
6. **返回键**：弹窗打开时 `OnBackButtonPressed` 先 `SortPicker.Close()`（否则系统返回键会直接返回上一级/退出浏览页，弹窗还留在屏幕上）。

### 8.3 图片预览左右滑动切换

**目标**：预览 jpg/png 等图片时，左右滑动即可切换**同目录**的其他图片，不用退回列表再点。

**做法**：

| 成员 | 作用 |
|---|---|
| `FileBrowserPage.PreviewAsync`（图片分支） | 从 `_displayedEntries` 里筛出图片（尊重当前**搜索过滤**与**排序**结果），组成 `List<PreviewImage>`（名称 + 远端路径）连起始下标一起传给预览页 |
| `Pages/PreviewPage.xaml.cs` | `PreviewImage` 记录；`Image` 上挂 `SwipeGestureRecognizer`（Direction=Left/Right） |
| `PreviewPage.RequestImage(index)` | 滑动入口：**立即**推进 `_targetIndex` 并按需加载；加载中再滑只记 `_pendingIndex` 并 `_cts.Cancel()` |
| `PreviewPage.LoadImageAsync(index)` | 循环：读取 → 被取消且有待载目标就继续 → 否则显示；`ReadBytesAsync(20MB)` 由预览页**按需读取**（不预载全部） |

**要点**：
1. **不一次性读全部图片**：浏览器只传清单，字节按需读取（单张上限 20MB），避免几十张图的目录把内存打爆。
2. **SMB 读取必须串行**：SMBLibrary 会话不是线程安全的，所以同一时刻只允许一次读取；新滑动通过 `CancellationToken` 打断当前读取（`ReadBytesAsync` 在 64KB 分块循环里检查取消），再接着读新目标。
3. **连滑要“跨多张”**：滑动目标基于 `_targetIndex`（滑动时立即推进）而不是 `_index`（加载完成才更新），否则快速连滑 3 次只会前进 1 张（实测踩过）。
4. **边界钳制**：`Math.Clamp(index, 0, count-1)`，第一张再右滑、最后一张再左滑都不动、不崩。
5. **标题即进度**：预览页沿用 Shell 导航栏标题，显示 `文件名 (当前/总数)`。
6. **取消时的清理**：离开预览页 `OnDisappearing` 取消未完成读取（把连接让给浏览页）；取消且无新目标时清掉已加载数据，返回页面会重新加载。
7. **提示文案不放在图片页**（避免遮挡图片）：写在连接页「帮助」的 `notes_text` 里 ——「图片预览可左右滑动，快速切换同目录下的其他图片」。
8. **排查日志**：`adb logcat -s FastSMB:I` 看 `Preview: image "xxx.jpg" (3/97) ok=True bytes=… cancelled=False`。

## 9. 关键踩坑记录（AI/新人必读）

1. **SMB 路径**：CREATE 的 Name 不带前导 `\`，根目录是 `""`。Samba 严格校验（`STATUS_INVALID_PARAMETER`）。
2. **QueryDirectory**：最后一批与 `STATUS_NO_MORE_FILES` 同时返回，先取结果再 break。
3. **MAUI 10.0.20 的 Entry 没有 `BorderColor`/`BorderWidth`**（模板 SourceGen 还会因它报 MAUIG1001，已禁用 SourceGen）。
4. **C# 插值字符串**：`$"{obj["key"]}"` 直接内嵌双引号**合法**；写成 `$"{obj[\"key\"]}"` 反而**报错**（.NET 10 编译器）。
5. **Android xml 资源**（如 file_paths.xml）必须放 `Platforms/Android/Resources/xml/`，放项目 `Resources/xml/` 会报 APT2260。
6. **Application 上下文启动 Activity** 必须 `FLAG_ACTIVITY_NEW_TASK`（系统播放器 Intent 曾因此静默失败）。
7. **FileProvider** 需 manifest 注册 + file_paths.xml；视频/音频用 `Intent.ActionView` + `GrantReadUriPermission`。
8. **CommunityToolkit.Maui**：15.x 需 MAUI≥10.0.90（NU1605）、12.x 需 Maui.Core<10（NU1107）、13.0.0 可装但已无 MediaElement —— 不采用。
9. uiautomator 无法 dump 持续动画的页面（idle 超时）；验证 UI 用截图 + 直方图/OCR。
10. 中文文本预览：`Encoding.RegisterProvider(CodePagesEncodingProvider.Instance)`（MauiProgram）注册后 GBK 可用；解码顺序 UTF-8(严格)→GBK→Default。
11. **MAUI ImageButton 在 Android 不尊重 WidthRequest**（图片按固有尺寸渲染，20dp 会显示 183px）→ 改用 `Image` + `TapGestureRecognizer`（Image 严格尊重尺寸），外层包 44px Grid 保证点击区域。连接页切换按钮与浏览器退出图标均用此法。
12. **文件选择器（FilePicker）/系统播放器打开期间 SMB 连接被回收**：打开系统应用会把本程序切到后台，期间服务器可能关闭空闲 SMB 连接；且 SMBLibrary 只有等 socket 接收回调处理完断开后 `IsConnected` 才为 false，在此之前 `EnsureConnected()` 可能误判连接仍有效，下一次操作直接抛 `InvalidOperationException("The client is no longer connected")`。
    - 修复：`App.CreateWindow` 订阅 `Window.Deactivated/Stopped` → `SmbSession.MarkConnectionStale()`；`EnsureConnected()` 一旦发现该标记就**无条件重建连接**（重连 + 重开共享）；并且 `ListDirectory / DownloadFileAsync / UploadFileAsync / ReadBytesAsync` 内部都先调 `EnsureConnected()`；`FileBrowserPage.OnAppearing` 从后台返回时先重连、失败才退回连接页。
13. **EnsureConnected 重连 Bug**：`Connect()` 内部 `Disconnect()` 会清空 `_share`，重连后 `OpenShare(_share)` 用空串报"共享名不存在" → 重连前先把共享名存局部变量。
14. **CollectionView 的 `Scrolled` 事件会被程序性滚动触发**（换 `ItemsSource` 时 Android 补发一次 index=0）：做浏览位置记忆时若不加过滤，会把刚存档的位置覆盖成顶部。过滤手段见 §8.1（`_loading` / `_restoringScroll` / 静默窗三个开关）。
15. **`ItemsSource` 赋同一个实例不会刷新列表**：就地排序（`List.Sort`）后必须 `ItemsSource = null` 再重新赋值，否则界面顺序不变（见 §8.2）。
16. **自定义弹窗（ContentView 覆盖层）不吃系统返回键**：弹窗打开时按返回会照常执行 `OnBackButtonPressed`（返回上一级甚至退出页面），弹窗还挂在屏幕上。需用页面级标志位拦截并调弹窗的 `Close()`（见 §8.2；`SharePickerView` 在连接页，返回键会退出应用，同样值得按此处理）。
17. **连续滑动切换图片时目标下标要用“待加载下标”**：若用「已显示下标」计算下一张，加载期间连滑多次只会前进一张。见 §8.3 要点 3。
