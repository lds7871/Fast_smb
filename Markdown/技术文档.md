# FastSMB 技术文档

> .NET MAUI Android SMB 客户端：连接 SMB 服务器 → 浏览共享目录 → 文件预览 / 单个下载 / 批量下载。
> 支持暗色/亮色主题切换、中英文语言切换。
> 本文档面向**用户与 AI**，帮助快速了解文件架构与关键知识点。最后更新：2026-09-13（对应 git 提交：语言切换功能之后）。

---

## 1. 技术栈与第三方包

| 项目 | 说明 |
|---|---|
| .NET MAUI | 目标框架 `net10.0-android`（Linux 上模板自动只保留 Android 目标），SDK 10.0.111 |
| C# | .NET 10 附带编译器（注意：插值字符串内嵌引号的规则，见 §8） |
| **SMBLibrary** 1.5.7.1 | 纯托管 SMB 客户端库（netstandard2.0），支持 SMB2/3，含 SMB1 回退。核心类型：`SMB2Client`、`SMB1Client`、`SMB2FileStore`、`FileDirectoryInformation` |
| Microsoft.Extensions.Logging.Debug | 模板自带，Debug 日志 |
| 无其他 UI 库 | 视频/音频预览**不用** CommunityToolkit.Maui（其 13.0.0 已移除 MediaElement，且高版本与 MAUI 10.0.20 不兼容），改用系统 Intent + FileProvider |

Android 侧依赖：`androidx.core.content.FileProvider`（视频/音频交给系统应用）。

## 3. 页面与导航

- **AppShell**：单 `ShellContent`（ConnectPage）+ `Routing.RegisterRoute("browser", FileBrowserPage)`。
- 连接成功 → `Shell.Current.GoToAsync("browser")` 压栈；浏览器根目录按返回 → 弹回连接页。
- **连接页 OnAppearing 会主动 `SmbSession.Disconnect()`**：退出到主界面即断开（产品约定）。
- 预览页用 `Navigation.PushAsync(new PreviewPage(...))` 直接压栈（不走路由，便于传字节数组）。
- 文件夹层级：`FileBrowserPage` 内部维护 `_pathStack`（返回键优先弹层级，而不是退出页面）。

## 4. SMB 核心实现（Services/SmbSession.cs + SmbClients.cs）

### 4.1 连接
1. `Smb2ClientEx.Connect(host, port)`：DNS 解析 → 取 IPv4 → 调 SMBLibrary 的 `protected internal Connect(IPAddress, DirectTCPTransport, port)`。
2. `Login("", user, pass)`（NTLMv2）。
3. SMB2 连接失败 → 回退 `Smb1ClientEx`（SMB1，forceExtendedSecurity=true）。
4. 主机栏支持三种写法：`IP` | `IP:端口` | `IP/共享名` | `IP:端口/共享名`（ConnectPage 解析，端口默认 445）。

### 4.2 共享与目录
- `ListShares()`：经 IPC$ 枚举，**过滤以 `$` 结尾的隐藏共享**（IPC$/ADMIN$ 等）。
- `OpenShare(share)`：`TreeConnect`，句柄存 `_fileStore`（SMB2FileStore 或 SMB1FileStore）。
- `ListDirectory(path)`：
  - **路径规则（重要）**：SMB2 CREATE 的 Name 必须是**相对共享、不带前导反斜杠**；根目录用空串 `""`。真实 Samba 对 `"\\"` 返回 `STATUS_INVALID_PARAMETER`（impacket 测试服务器宽容，掩盖了此问题）。
  - **QueryDirectory 语义（重要）**：返回最后一批条目时同时带 `STATUS_NO_MORE_FILES`——必须**先处理 results 再判断退出**，否则目录永远为空。
  - `FileDirectoryInformation` 的字段是**公共字段**（FileName/EndOfFile/FileAttributes/LastWriteTime），不是属性。

### 4.3 下载
- `DownloadFileAsync(path, Stream output, IProgress<double>, CancellationToken)`：
  CreateFile(GENERIC_READ) → GetFileInformation(FileStandardInformation) 取大小 → 循环 ReadFile（64KB）→ 写入调用方提供的 Stream。
- 落盘由 `DownloadSaver.CreateDownloadStream` 决定：Android 10+ 用 MediaStore（公共下载目录，免权限）；旧版直写公共目录；其他平台写应用数据目录。

## 5. 主题切换（暗色/亮色）

### 5.1 涉及文件
| 文件 | 作用 |
|---|---|
| `Resources/Styles/ThemeColors.xaml` | **色板**：语义键 × Light/Dark 两个 `Color` 资源（Bg、Surface、Surface2、Surface3、Border、TextPrimary、TextSecondary、TextBody、TextOnAccent、Accent、Link、Error、Success、Scrim） |
| `App.xaml` | 把 ThemeColors.xaml 合并进全局资源（放在模板 Colors/Styles 之前） |
| `App.xaml.cs` | 构造函数：`UserAppTheme = Theme.Load()`（从 Preferences 恢复） |
| `Services/Theme.cs` | 切换与取色工具 |
| `Pages/ConnectPage.xaml(.cs)` | 切换按钮（右上角 🌙/☀️） |
| 所有页面 XAML | 颜色一律 `{AppThemeBinding Dark={StaticResource XxxDark}, Light={StaticResource XxxLight}}` |

### 5.2 方法
- **XAML**：`{AppThemeBinding Dark={StaticResource AccentDark}, Light={StaticResource AccentLight}}`——随 `Application.Current.UserAppTheme` **自动、即时**刷新（MAUI 内建机制，Shell 导航栏颜色由模板 Styles.xaml 同理自动跟随）。
- **切换**：`Theme.Toggle()` → `Application.Current.UserAppTheme = 暗/亮` → `Preferences.Set("theme", …)`。
- **代码取色**：`Theme.Get("Accent")` —— 按 `UserAppTheme` 返回 `AccentDark` 或 `AccentLight` 资源值（用于代码创建的 UI，如 TopBannerView 错误色、SharePickerView 动态按钮）。
- **启动恢复**：App 构造函数读 `Preferences("theme")`（默认 dark）。

## 6. 语言切换（中文/英文）

### 6.1 涉及文件
| 文件 | 作用 |
|---|---|
| `Services/L10n.cs` | **本地化管理器**：`Zh`/`En` 两套 `Dictionary<string,string>`（约 75 个 key，含 SmbSession 错误文案）；`IsEnglish`；`this[key]` 索引器；`SetLanguage(bool)`（触发 INotifyPropertyChanged 全量刷新）；`Load()`（Preferences 恢复） |
| `App.xaml.cs` | 构造函数：`L10n.Instance.Load()` |
| `Pages/ConnectPage.xaml(.cs)` | 语言按钮（右上角「中 / EN」） |
| 所有页面 XAML | 文本绑定：`{Binding [key], Source={x:Static l10n:L10n.Instance}}` |

### 6.2 方法
- **XAML 绑定模式**：`Text="{Binding [notes_title], Source={x:Static l10n:L10n.Instance}}"`。
  `L10n` 用**字符串索引器** + `PropertyChanged(null)`（全属性刷新），切语言时所有此类绑定即时更新。
- **代码取文本**：`L10n.Instance["key"]`（如进度标签 `$"{L10n.Instance["downloading"]} {entry.Name} …"`）。
- **切换**：`L10n.Instance.SetLanguage(!IsEnglish)` → 存 `Preferences("lang")` → 全量刷新。
- **启动恢复**：App 构造函数 `L10n.Instance.Load()`（默认 zh）。
- ⚠️ 数据模板内使用本地化绑定时，**不要写 `x:DataType`**（编译绑定与 `Source={x:Static}` 组合易出错）；FileBrowserPage 的条目模板已移除 x:DataType，退回运行时绑定。

### 6.3 增加新文案的步骤
1. `L10n.cs` 的 `Zh`/`En` 各加一个 key。
2. XAML 里用 `{Binding [key], Source={x:Static l10n:L10n.Instance}}`；代码里 `L10n.Instance["key"]`。

## 7. 功能要点速查

| 功能 | 文件/方法 | 说明 |
|---|---|---|
| 单个下载 | `FileBrowserPage.DownloadOneAsync` + `DownloadSaver.CreateDownloadStream` | 行内「⬇ 下载」按钮触发；进度面板 + 顶部横幅 |
| 批量下载 | `FileBrowserPage.OnBatchDownloadClicked` | 顶栏「批量」进入（文字不变），底部面板 全选/反选/全不选/取消批量/下载所选(N)；顺序逐个下载，`_batchAbort` 支持取消；完成后横幅汇总 |
| 批量勾选 | `Models/SmbEntry.cs`（INPC） | `IsBatchMode`/`IsSelected`/`ShowCheckbox`/`ShowDownloadButton` 驱动模板切换 ⬇ 按钮 ↔ 勾选框 |
| 文件预览 | `FileBrowserPage.PreviewAsync` → `PreviewPage` | 文本（≤512KB，UTF-8 严格→GBK→默认）/图片（≤20MB）；视频/音频 → 下载到 `FileSystem.CacheDirectory` 后 FileProvider + Intent（`video/*`、`audio/*`）调系统应用 |
| 搜索 | `FileBrowserPage.ApplySearch` | 顶栏「搜索」弹出搜索栏，实时按名过滤；批量操作只作用于**显示列表** `_displayedEntries`；导航时自动清空 |
| 加载动画 | `FileBrowserPage.LoadDirectoryAsync` + `LoadingPanel` | 加载期间清空列表并全页遮盖（防看到上一级残留），`_loading` 防重入 |
| 目录加载 | `SmbSession.ListDirectory` | QueryDirectory 每批处理后判断退出（见 §4.2） |
| 记住输入 | `ConnectPage.SaveRemember` | Preferences：`remember_host/user/pass/share` |
| 自动断开 | `ConnectPage.OnAppearing` | 只要回到连接页就 `Disconnect()` |
| 下载落盘 | `Services/DownloadSaver.cs` | MediaStore（API29+）/公共目录/应用目录 三分支 |

## 8. 关键踩坑记录（AI/新人必读）

1. **SMB 路径**：CREATE 的 Name 不带前导 `\`，根目录是 `""`。Samba 严格校验（`STATUS_INVALID_PARAMETER`）。
2. **QueryDirectory**：最后一批与 `STATUS_NO_MORE_FILES` 同时返回，先取结果再 break。
3. **MAUI 10.0.20 的 Entry 没有 `BorderColor`/`BorderWidth`**（模板 SourceGen 还会因它报 MAUIG1001，已禁用 SourceGen）。
4. **C# 插值字符串**：`$"{obj["key"]}"` 直接内嵌双引号**合法**；写成 `$"{obj[\"key\"]}"` 反而**报错**（.NET 10 编译器）。
5. **Android xml 资源**（如 file_paths.xml）必须放 `Platforms/Android/Resources/xml/`，放项目 `Resources/xml/` 会报 APT2260。
6. **Application 上下文启动 Activity** 必须 `FLAG_ACTIVITY_NEW_TASK`（系统播放器 Intent 曾因此静默失败）。
7. **FileProvider** 需 manifest 注册 + file_paths.xml；视频/音频用 `Intent.ActionView` + `GrantReadUriPermission`。
8. **CommunityToolkit.Maui**：15.x 需 MAUI≥10.0.90（NU1605）、12.x 需 Maui.Core<10（NU1107）、13.0.0 可装但已无 MediaElement —— 不采用。
9. uiautomator 无法 dump 持续动画的页面（idle 超时）；验证 UI 用截图 + 直方图/OCR。
10. 中文文本预览：`Encoding.RegisterProvider(CodePagesEncodingProvider.Instance)`（MauiProgram）注册后 GBK 可用；解码顺序 UTF-8(严格)→GBK→Default。
